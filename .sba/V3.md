# NAccount SBA v3 生命周期

任务 `NACCOUNT-SBA-V3-S01`。应用版本 `3.0.0`，仅接受 manifest/request v3；不保留 v2
程序入口兼容分支。原人工 CLI 独立保留，不将其结果当 v3 回执。平台负责新建声明中的
独立 D1/KV；应用负责迁移、密钥、构建、发布和精确测试清理。

## 地址和版本

自动资源声明默认生成 `{instance}-auth`、`{instance}-admin` 两个 Worker 及两个
`workers.dev` 地址，也接受用户显式自定义域名。`global_fetch_strictly_public` 明确加入
两端配置，使 admin 对 auth 的 fetch 经过 Cloudflare 公网入口；不绕过 Access 或防火墙。
这条机制已核对官方文档，真实双 Worker 登录仍须线上验收。不得根据 build/dry-run 宣称成功。

- https://developers.cloudflare.com/workers/runtime-apis/fetch/
- https://developers.cloudflare.com/workers/configuration/compatibility-flags/#global-fetch-strictly-public

## 动作

- `deploy`：固定源码构建、初始化目标 KV 密钥、迁移目标 D1、发布 server，再从实际数据库
  读取 admin 客户端、配置回调、构建和发布 admin。readiness 不等于注册、邮件等业务验收，
  返回 `deployed-unverified`。
  deploy/preview 在首次云写入前拒绝已有同名 Worker 或域名；读取失败不视为不存在。
  供应商预检与后续发布不是原子 create-only，执行期间不得由外部操作者并发占用这些名称。
- `update`：复用资源和 KV 密钥，取得 D1 SQL 导出与 Time Travel bookmark，迁移后投影旧列
  校验所有原有行的值及重复数量、检查外键，再发布。不只是比较行数。任一不允许的数据变化
  拒绝签署 `data-preserved`，不自动回滚或重试。
- `verify`：只做 OIDC discovery、JWKS、admin HTTP 就绪检查。
- `preview`：复制同一时点 D1 导出到空目标库，校验复制、迁移及原有行；目标 KV 必须为空且
  新生成认证密钥。在任何 Worker 对外发布前禁用非 admin 应用与 SAML IdP，替换 admin 回调，
  生成并读回新的 admin S2S secret。源配置和数据只读；结束时再次比较源旧表/列/行，若期间
  有并发变化则保留不确定结果，不能签署源未变化。
- `destroy-preview`：仅接受 `test-<12 hex>` 实例及精确六项清单；先核对 D1/KV 名称、Worker
  bindings、域名归属，再逐项删除并回读。不按资源名前缀批量清理。404 可为 absent，权限或
  网络错误不能冒充不存在；任何部分失败保留 unknown，不允许把它称为已删除。

## 预升级隔离不是生产状态完全克隆

持久业务快照为 D1。KV 包含会话、MFA、锁定与认证材料，没有提供跨 D1/KV 一致快照的
官方能力。本应用明确使用全新 KV，因此源登录会话、账号/IP 锁定、remember-device、
验证码和 SAML key 等认证状态不复制；不能据此验收这些状态的迁移。

测试环境是 D1 数据副本加隔离配置：非管理员 OAuth 应用和 SAML IdP 禁用，社交/OIDC
客户端配置及 embedded origins 清空，不会把复制的客户端引向原应用。构建生成固定 wrapper：
server 禁止全部 global fetch，admin 只可访问新 auth origin、禁止自动跟随 redirect；移除
SMTP/send_email、services、定时与队列配置，拦截外域 Location 并限制浏览器 CSP。
两个线上 wrapper 均有只读隔离探针，未验证实际探针不能签署 `side-effects-isolated`。
邮件/SMS/社交登录等真实外部集成不属于隔离预升级的业务验收。

## 快照、备份及限制

D1 export 是一致导出，但执行期间源数据库不能服务其他查询，需安排可接受的测试窗口。
本实现有界处理 64 MiB SQL、100 个业务表、每表 100000 行；不支持的虚表/类型或超过界限
失败关闭，不删除源库对象来绕过导出限制。源数据不写公共结果或日志。

SQL 只存 runner 私有临时目录，runner 销毁后不承诺文件保留；signed URL 仅一小时有效。
update 的 `NACCOUNT_D1_RECOVERY_POINT` 日志记录公开数据库 ID、bookmark 和取点时间，
可在 Cloudflare 原数据库仍存在时执行有界 Time Travel 恢复。官方 Free 为 7 天、Paid 为
30 天，本实现只按至少 7 天说明；数据库删除后的恢复没有承诺，也没有执行自动恢复。
取得恢复点不等于实际演练恢复成功。

- https://developers.cloudflare.com/d1/best-practices/import-export-data/#known-limitations
- https://developers.cloudflare.com/d1/reference/time-travel/
- https://developers.cloudflare.com/d1/platform/limits/
- https://developers.cloudflare.com/kv/concepts/how-kv-works/

网络与 redirect guard、非法源/目标拒绝、按 ID 清理和部分失败 unknown。云供应商测试
为合成替身；无凭据真实构建、Cloudflare 真执行和登录/邮件业务验证分别报告。
