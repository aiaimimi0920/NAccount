# 认证界面语言

认证页已有英文、法文与简体中文翻译。开发配置 `melody-auth/server/wrangler.toml` 默认启用 `en`、`fr`、`zh`；正式 `.sba` 环境模板已启用 `en`、`zh`。

统一入口 `server/src/utils/request.ts` 的语言选择顺序：

1. 请求中明确指定且受支持的 `locale`，包括用户在语言选择器中的选择。
2. 浏览器 `Accept-Language`，按 `q` 权重降序匹配已启用的语言；相同权重保留浏览器顺序。
3. `SUPPORTED_LOCALES` 的第一项。

地区标签匹配基础语言，如 `en-US` 匹配 `en`、`zh-CN` 和 `zh-Hans` 匹配 `zh`。当前只有简体中文翻译，`zh-TW` 同样回退到简体中文，不表示已提供繁体翻译。零权重及非法权重不参与自动选择。后续认证流程使用现有 locale 传递机制。
